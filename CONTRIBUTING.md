# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Thank you for taking the time to contribute to the Simple Interest Calculator project.

## Getting Started

1. **Fork** this repository to your own GitHub account.
2. **Clone** your fork to your local machine:
   ```bash
   git clone https://github.com/<your-username>/mcino-Introduction-to-Git-and-GitHub.git
   ```
3. **Create a branch** for your work:
   ```bash
   git checkout -b my-feature-branch
   ```

## Making Changes

1. Make your changes in your branch.
2. Test the script to confirm it still works as expected:
   ```bash
   bash simple-interest.sh
   ```
3. Stage and commit your changes with a clear message:
   ```bash
   git add .
   git commit -m "A short description of what you changed"
   ```
4. Push the branch to your fork:
   ```bash
   git push origin my-feature-branch
   ```
5. Open a **pull request** against the `main` branch of this repository.

## Reporting Bugs

If you find a bug, please open an issue and include:

- A clear and descriptive title
- The steps required to reproduce the problem
- What you expected to happen, and what actually happened
- Your operating system and shell version

## Suggesting Enhancements

Enhancement suggestions are tracked as GitHub issues. When opening one, please explain the improvement you have in mind and why it would be useful to other users of the project.

## Improving Documentation

Documentation improvements are just as valuable as code changes. Corrections to typos, clearer explanations, and additional examples are all appreciated.

## Style Guidelines

- Keep shell scripts readable and add comments where the logic is not obvious.
- Use descriptive variable names.
- Write commit messages in the present tense, for example "Add input validation" rather than "Added input validation".

## Code of Conduct

By participating in this project, you agree to abide by the terms set out in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
